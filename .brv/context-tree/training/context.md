# Domain: training

## Purpose
Contains knowledge about model training experiments, architecture snapshots, optimization work, and execution plans for the Parameter Golf project.

## Scope
Included in this domain:
- Model architecture summaries
- Training experiment milestones and metrics
- Optimization and bug-fix outcomes
- Run plans and production training next steps

Excluded from this domain:
- General repository housekeeping
- Unrelated infrastructure outside model training work

## Ownership
Parameter Golf project

## Usage
Use this domain for concise, traceable summaries of training progress and experiment direction.
